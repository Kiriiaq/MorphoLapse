# MorphoLapse v1.0.0

## 🎉 First Stable Release

Professional Face Morphing & Time-Lapse Video Creator.

### ✨ Features

- **Face Detection**: Automatic facial landmark detection
- **Photo Alignment**: Align photos based on face position
- **Morphing Animation**: Smooth transitions between photos
- **Video Export**: Export as MP4/AVI/GIF
- **Batch Processing**: Process entire photo collections

### 📦 Downloads

| File | Description |
|------|-------------|
| `MorphoLapse-1.0.0-release.exe` | Production build (no console) |
| `MorphoLapse-1.0.0-debug.exe` | Debug build (with console) |

### 🔧 Requirements

- Windows 10/11
- No installation required

### 📝 Keywords

Face morphing, time-lapse video, facial recognition, photo animation, video creator
